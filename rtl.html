آزمایش راست‌به‌چپ

نوار کناری در سمت راست، متن فارسی با وزیرمتن و کد همیشه چپ‌به‌راست.

متن ترکیبی فارسی و انگلیسی

کد، کلید و شناسه‌ها درون جملهٔ فارسی جهت خود را حفظ می‌کنند.

برای ارسال درخواست از کلید sk_live_4fJk9Lm2Xp و نقطهٔ پایانی POST /v1/emails استفاده کنید. شناسهٔ درخواست req_8Fk2mQx1Zw پس از ارسال بازگردانده می‌شود.

بلوک کد — همیشه چپ‌به‌راست

curl https://api.apiforge.dev/v1/emails \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{ "to": "user@example.com" }'
import { ApiForge } from '@apiforge/sdk';

const client = new ApiForge('YOUR_API_KEY');
await client.emails.send({ to: 'user@example.com' });

قواعد

  • ویژگی‌های منطقی (logical properties) باعث آینه‌شدن خودکار چیدمان می‌شوند.
  • کد با dir="ltr" و کلاس ltr-isolate ایزوله می‌شود.
  • اعداد فارسی با کلاس num-fa: ۱۲۳۴۵۶۷۸۹۰
