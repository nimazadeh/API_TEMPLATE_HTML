## Title

**APIForge X — Premium API Infrastructure HTML Template (Bootstrap 5 + SCSS + Vite, Persian RTL & LTR)**

## Short description

A specialized developer-platform template: dashboards, request logs, a Stripe-grade webhook debugger, reveal-once API keys, billing and docs. Persian-first with a live English/LTR switch, 31 hand-built pages, no React, no Tailwind, no CDN.

## Long description

**APIForge X** is not another admin theme. It is a purpose-built HTML template for API platforms — AI APIs, infrastructure APIs, BaaS and SaaS developer tools — in the spirit of Stripe, Resend, Vercel and Linear.

Every page is deep and interactive, backed by deterministic mock data, so the demo works the moment you open it.

**Workspace:** overview KPIs and charts, API explorer and tester, endpoint management, reveal-once API keys, request log inspector with copy-as-cURL, webhook debugger, errors, rate limits, usage, metrics, environments, team, billing, settings, profile, notifications.

**Docs:** documentation portal, SDK catalog, API reference.

**Marketing & auth:** landing, pricing, changelog, status, 404, login, forgot password, invite.

**Bilingual (fa ⇄ en):** two complete catalogs, live header switch, no reload, Jalali dates and Persian digits in Farsi, LTR isolation for code and keys.

**RTL engineering:** logical CSS properties throughout, not a bolted-on `direction: rtl`.

**Stack:** HTML5, Bootstrap 5.3, SCSS tokens, Vite 7, Lucide, Chart.js, self-hosted Vazirmatn / Inter / JetBrains Mono.

**You get:** HTML production files (upload anywhere) + full Vite source + buyer documentation + listing screenshots.

**License:** Regular and Extended (see LICENSE.txt). Extended covers unlimited end-product sales.

The template is a static front-end with simulated authentication. It does not include a live backend.
