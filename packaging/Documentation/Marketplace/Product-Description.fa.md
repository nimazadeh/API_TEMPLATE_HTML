# توضیح محصول — راست‌چین

## عنوان

**APIForge X — قالب HTML پریمیوم برای پلتفرم‌های API (بوت‌استرپ ۵ + SCSS + Vite، فارسی RTL و انگلیسی LTR)**

## توضیح کوتاه

قالبی تخصصی برای پلتفرم‌های توسعه‌دهنده: داشبورد، لاگ درخواست، دیباگر وب‌هوک در سطح Stripe، کلید API با نمایش یک‌باره، صورت‌حساب و مستندات. **فارسی‌محور** با تغییر زنده به انگلیسی، ۳۱ صفحهٔ دست‌ساز، بدون React، بدون Tailwind، بدون CDN.

## توضیح کامل

**APIForge X** یک قالب ادمین عمومی نیست. قالب HTML تخصصی برای پلتفرم‌های API است — هوش مصنوعی، زیرساخت، BaaS و ابزارهای SaaS — با کیفیتی در حد Stripe، Resend، Vercel و Linear.

هر صفحه عمیق و تعاملی است و با دادهٔ نمایشی قطعی کار می‌کند؛ دمو از لحظهٔ باز شدن آماده است.

**فضای کاری:** نمای کلی و نمودارها، کاوشگر و تستر API، مدیریت endpoint، کلیدهای API، بازرس لاگ با کپی cURL، دیباگر وب‌هوک، خطاها، محدودیت نرخ، مصرف، متریک، محیط‌ها، تیم، صورت‌حساب، تنظیمات، نمایه، اعلان‌ها.

**مستندات:** پورتال راهنما، کاتالوگ SDK، مرجع API.

**بازاریابی و ورود:** فرود، قیمت، تغییرات، وضعیت سرویس، ۴۰۴، ورود، بازیابی رمز، دعوت.

**دوزبانه (فارسی ⇄ انگلیسی):** دو کاتالوگ کامل، تغییر زبان از هدر بدون رفرش، تاریخ شمسی و ارقام فارسی، ایزولهٔ LTR برای کد و کلید.

**مهندسی راست‌به‌چپ:** ویژگی‌های منطقی CSS در سراسر قالب.

**فناوری:** HTML5، Bootstrap 5.3، توکن‌های SCSS، Vite 7، Lucide، Chart.js، فونت‌های محلی وزیرمتن / Inter / JetBrains Mono.

**آنچه دریافت می‌کنید:** فایل‌های HTML آمادهٔ آپلود + سورس کامل Vite + راهنمای خریدار + تصاویر لیستینگ.

**لایسنس:** عادی و Extended (فایل LICENSE.txt). این قالب فرانت استاتیک با احراز هویت شبیه‌سازی‌شده است و بک‌اند زنده ندارد.
