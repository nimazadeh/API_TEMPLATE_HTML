# Requirements

## HTML-Version

- Any static web server or host (Apache, Nginx, cPanel, Netlify, Vercel, object storage with web hosting)
- Modern browsers: current Chrome, Edge, Firefox, Safari
- No Node.js, no database, no PHP

## Source-Version

- Node.js 20+
- npm 10+
- Optional: Chromium for Playwright

## Browser support (product)

Designed for evergreen desktop and mobile browsers. Automated regression in this release is **Chromium**. Safari, Firefox, and physical devices are not separately certified.

## What this is not

- Not a live API gateway
- Not a real authentication or billing provider
- Not a WordPress / Laravel theme
