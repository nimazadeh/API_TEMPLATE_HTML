# Getting started with APIForge X

Welcome — and thank you for choosing APIForge X, a premium developer-platform
HTML template by **Blue Studio**.

Your download contains two packages:

| Package | What it is | When to use it |
|---------|------------|----------------|
| `APIForge-X.zip` | The complete, ready-to-run template — 30 HTML pages, stylesheets, scripts and self-hosted fonts | Previewing, customizing HTML directly, or deploying to any static host |
| `APIForge-X-Developer.zip` | The full Vite + SCSS source the template is built from | Changing design tokens, components, translations or adding pages |

---

## 1. Look around first (30 seconds, no tools)

1. Unzip `APIForge-X.zip`.
2. Open the extracted folder and double-click **`index.html`**.

That's it. The template opens straight from your file system — no server, no
Node.js, no internet connection required. Every asset (styles, scripts,
fonts, icons) is local, so nothing can be blocked by the network.

Things worth trying on the first pass:

- The **language toggle** in the header — the whole interface flips between
  Persian (RTL) and English (LTR) live, without a reload.
- The **theme menu** — dark, light, and a system mode that follows your OS.
- `dashboard.html`, `logs.html`, `webhooks.html`, `api-keys.html` — the
  workspace surfaces, complete with working charts and seeded demo data.
- Press **Ctrl / ⌘ K** inside any workspace page for the command palette.

## 2. Put it online

The package is plain HTML/CSS/JS with relative paths — upload the *contents*
of the extracted folder to any static host (cPanel, Nginx, Netlify, Vercel,
object storage) and it just works, including in sub-directories.
See `installation.md` for host-specific notes.

## 3. Make it yours

Two routes:

- **Quick edits** — open any `.html` file in an editor and change copy,
  links, or structure. Each page is self-contained markup.
- **Deep customization** — unzip `APIForge-X-Developer.zip`, run
  `npm install && npm run dev`, and work from the SCSS token system and
  modular JavaScript. `customization.md` walks through the whole workflow.
