    یک قالب مدیریتی معمولی نیست

    هر صفحه با هدفی مشخص برای زیرساخت API ساخته شده است؛ عمیق، تخصصی و تعاملی — نه مجموعه‌ای از کارت‌های تکراری.

    کاوشگر لاگ درخواست‌ها جدول‌های فشردهٔ درخواست‌ها با وضعیت، تاخیر پاسخ و شناسهٔ درخواست، به همراه یک بازرس کامل — هدرها، بدنهٔ درخواست، زمان‌بندی و کپی در قالب cURL. بررسی لاگ‌ها اشکال‌زدای وب‌هوک خط زمانی تحویل، وضعیت تلاش‌های مجدد و بازرس بدنه به همراه ابزارهای امضا — ابزار وب‌هوک در سطح استرایپ. اشکال‌زدایی یک تحویل کلیدهای API با نمایش یک‌باره کلیدهای پوشیده با امکان نمایش یک‌باره، چرخش، ابطال و ساخت با سطح دسترسی مشخص. همان تجربهٔ امنیتی که کاربرانتان انتظار دارند. مدیریت کلیدها تستر درخواست زنده کاتالوگ APIها را مرور کنید و درخواست واقعی با تزریق کلید، تب‌های مختلف و پاسخ JSON ارسال کنید. آزمایش یک نقطهٔ پایانی مانیتورینگ خطاها خطاها همراه با ردیابی پشته، زمینهٔ درخواست و فیلتر شدت — اطلاعاتی که به اقدام منجر می‌شود، نه فقط شمارش خطا. بررسی یک خطا فارسی و راست‌به‌چپ، درجه‌یک فونت وزیرمتن، ویژگی‌های منطقی CSS و جداسازی کدهای چپ‌به‌راست. یک دموی کامل فارسی همراه قالب عرضه می‌شود — بدون هیچ ترفندی. مشاهدهٔ نسخهٔ دموی فارسی

    دقیقاً همان‌طور که خودتان می‌سازید

    HTML5، Bootstrap 5، SCSS با توکن‌های طراحی، ماژول‌های ES و Vite. فونت‌های محلی، آیکون‌های بهینه‌سازی‌شده و Chart.js. نه خبری از React است، نه Tailwind و نه CDN — هیچ چیزی بین شما و کدها قرار ندارد.

    • ویژگی‌های منطقی در همه‌جا — با dir="rtl" کل برنامه را راست‌به‌چپ کنید
    • پوسته‌های تیره، روشن و سیستم با اسکریپت داخلی بدون پرش تصویر
    • داده‌های قطعی مبتنی بر seed — بازتولید هر مجموعه‌داده با یک اسکریپت
    curl https://api.apiforge.dev/v1/emails \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "to": "dev@example.com", "subject": "Ship faster" }'
    import { ApiForge } from '@apiforge/sdk';

const client = new ApiForge('YOUR_API_KEY');
await client.emails.send({
  to: 'dev@example.com',
  subject: 'Ship faster',
});
